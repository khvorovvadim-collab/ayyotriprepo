## Расхождения, которые надо закрыть

1. **Рекламных стартов (412) больше, чем слушателей в Студии (252).** Либо шапка Студии показывает более короткий период, либо Студия засчитывает слушателя не с первой секунды, и часть рекламных стартов — это пропуски трека.
2. **Добавлений за сутки (~19) больше, чем рекламных стартов в день в среднем (~11).** Либо бюджет в последние дни был выше среднего, либо заметная часть добавлений приходит не из рекламы. Проверяется по статистике рекламы с разбивкой по дням.

## Экономика — проверка допущения

По словам Вадима, примерно за 1 млн прослушиваний он получил со стримов $250–300 за всё время, то есть ~$0,0003 за прослушивание. При курсе 80–100 ₽ за доллар это 2–3 копейки. Добавление, которое потом даст 20–30 прослушиваний, приносит меньше 1 ₽. Значит, реклама по 10–50 ₽ за добавление напрямую со стримов не окупится никогда. Её смысл только в одном: запустить органику через рекомендации и нарастить базу слушателей. Поэтому решения о масштабировании принимаем по росту рекомендаций, а не только по цене добавления.
